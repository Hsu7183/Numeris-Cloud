# Numeris 彩球分析與選號系統

Numeris（數序計畫）是一套完全在本機執行的官方歷史開獎資料管理、描述統計、條件式選號、推薦保存、開獎核對及歷史逐期模擬系統。核心選號使用可重現的 NumPy PCG64 演算法，不使用 OpenAI API、語言模型或付費AI服務。

> 本系統不預測未來結果，也不提供購買、代購、投注、金流或遠端下單功能。

## 安裝

1. 安裝 Python 3.12 以上版本。
2. 在檔案總管開啟專案根目錄。
3. 雙擊 `setup.bat`。它會建立專案內 `.venv`、安裝依賴與 Playwright Chromium、執行 Alembic migration、初始化8種啟用商品及preset，並匯入固定測試fixture。

本機若只有 Python 3.13，安裝程式會顯示版本差異後使用相容環境。

## 啟動

雙擊 `run.bat`，或在命令提示字元執行：

```bat
run.bat
```

瀏覽器會開啟 <http://127.0.0.1:8767/>。伺服器只綁定 `127.0.0.1`，不對區域網路公開。

若Numeris已經在背景執行，再次雙擊`run.bat`會直接開啟現有頁面，不會重複啟動。
在瀏覽器按`F11`會使用全螢幕橫式首屏；也可以按頁面右上角的「全螢幕」按鈕。

## 簡易首頁

首頁只保留四個主要動作：

1. 選擇彩種，直接查看或建立下期組合。
2. 使用精選10組，或對適用彩種選擇7／8／9碼包牌。
3. 查看推薦的開獎前定錨碼，以及目前是等待開獎或已完成核對。
4. 查看只由實戰定錨紀錄計算的每週達標率與號碼正確率。
5. 切換「近10週回測定錨」，查看每週日期範圍、達標期數、號碼正確率與週定錨碼。

7碼、8碼及9碼包牌會分別依該彩種的單式選取數完整展開排列組合。例如六合彩
6選7為7組、6選8為28組、6選9為84組。包牌只保證列出所選核心號碼的完整單式，
不代表核心號碼包含未來開獎號碼。

簡易首頁建立的推薦會立即保存與鎖定，並以目標期別、資料截止期、鎖定時間、
完整設定與全部組合建立SHA-256定錨。資料更新後，只有「推薦目標期別」與
「實際開獎期別」完全相同、開獎資料寫入時間晚於鎖定時間且定錨仍有效才會納入
首頁實戰統計；同一目標期只採最早鎖定的一份推薦。

「達標率」是每期10組中至少1組達到固定命中門檻的實戰期數比例；「號碼正確率」
是命中主要號碼總數除以核對號碼總數。首頁不混入歷史回放；沒有合格樣本時顯示
「等待驗證」。兩者都不是未來中獎機率。

「近10週回測定錨」會在每個歷史目標期只使用該期以前的資料重建固定10組，再將
預測輸入與組合建立SHA-256週定錨。它是現在建立的可重現回測證據，不代表那些歷史
開獎前真的已保存推薦，因此和「實戰逐期」分頁分開顯示、分開統計。
執行官方資料更新時，系統會比對最新開獎與回測截止期；有新資料才自動重建8個
啟用彩種的近10週結果，沒有新期別就直接沿用現有定錨。

## 資料更新

可在「資料中心」按下全部、台灣、香港或重新對帳，也可執行：

```bat
update_data.bat all
update_data.bat taiwan
update_data.bat hongkong
update_data.bat reconcile
```

系統只接受官方網域為正式來源，會保存原始檔、URL、時間、HTTP狀態、內容類型、大小與SHA-256。來源格式不能安全辨識時，原始檔只會標記為待解析，不會產生猜測資料。

## 手動匯入

範本在 `data\fixtures\import_template.csv`。必要欄位：

`market_code, game_code, draw_no, draw_date, pool_code, number_1...number_N, special_number, source_reference`

在「資料中心」選擇CSV、XLSX或XLS檔。匯入前會檢查號碼數量、範圍、重複、特別號、期別及日期；同一檔重複匯入不會增加資料筆數。衝突資料只標記，不會靜默覆蓋。

## 影片五步選號法 V1

1. 選擇彩種、目標期別與最近N期。
2. 查看冷、溫、熱號及遺漏值，設定包含與排除號碼。
3. 設定奇偶、大小及區間結構。
4. 使用該彩種歷史AC常見範圍，或設定手動範圍；3／4星彩改用數字結構。
5. 設定組數、random seed與最大重疊，產生差異化組合。

候選不足時，系統會回報衝突與建議，不會偷偷放寬條件。

## random seed

相同彩種、資料截止期、完整設定、程式版本及random seed會產生相同組合。要探索另一批合法組合，請建立新run並使用不同seed；既有run不會被修改。

## 推薦鎖定

「鎖定本次推薦」會寫入鎖定時間、SHA-256推薦定錨及稽核日誌。鎖定後若目標期、
設定或球號遭修改，定錨驗證會失敗並禁止計分；任何合法參數變更都應建立新的
generation run。

## 開獎結果核對

在「開獎結果核對」輸入run UUID與實際期別。大樂透及六合彩計算正碼命中與是否包含特別號；威力彩分區核對；3／4星彩計算相同位置與完整命中。沒有完整官方獎等或獎金資料時，只顯示號碼命中，不推測獎金。

## 歷史逐期模擬

模擬第N期時只使用第N期以前資料。週更使用`VIDEO_FIVE_STEP_V1`影片五步法，
依序重建當期可取得的頻率、遺漏、冷熱、結構與差異化組合，再與實際開獎比對。
每期保存預測球號、實際球號、命中球、命中數、命中率及
`future_data_used=false`證據。沒有已驗證逐期獎金資料時不計算ROI。

## 資料來源與驗證狀態

- 台灣：透過`api.taiwanlottery.com`官方年度檔API取得2007～2026年度ZIP，
  並以官方當月查詢API補齊最新期別；保存API回應、ZIP、網址、時間與SHA-256。
  已安全解析大樂透、威力彩、今彩539、3星彩及4星彩。
- 香港：透過香港賽馬會結果頁實際使用的官方GraphQL端點，
  分季取得1993～2026六合彩結果並驗證6個正碼及1個特別號。
- fixture：安裝時建立的固定測試資料，介面及資料庫均標記為`fixture`，不冒充正式資料。
- 39樂合彩及49樂合彩的衍生獎等、逐期完整獎金需要官方規則與資料人工確認後才會啟用。
- `update_data.bat all`會保留已驗證舊年度快取，只重新檢查本年度及當月資料。

## 備份與還原

執行 `backup.bat`。SQLite使用一致性backup API，設定檔另存ZIP，保存於`data\backups\時間戳`，預設只保留最近10份。還原前先關閉Numeris，再以備份的`numeris.sqlite3`取代資料庫檔並確認設定。

## 測試

執行 `test.bat`，依序執行ruff、mypy及pytest＋coverage。核心演算法覆蓋率門檻為85%，並包含AC、冷熱、遺漏、所有生成器、seed重現、差異化、防止未來資料及API整合測試。

## 常見錯誤

- **8767已被占用**：關閉既有Numeris視窗或使用該連接埠的程式。
- **雙擊run.bat沒有新視窗**：新版會先檢查背景服務；若已在執行，會直接開啟瀏覽器。
- **沒有可分析資料**：執行`update_data.bat all`下載官方資料，或在資料中心匯入官方檔。
- **候選組合不足**：依診斷調整最大重疊、AC、奇偶、大小、包含或排除條件。
- **官方下載失敗**：查看「系統工作」及`logs\numeris_YYYYMMDD.log`，使用官方檔手動匯入；不得改用來路不明第三方資料。
- **Playwright安裝失敗**：網路恢復後執行`.venv\Scripts\python.exe -m playwright install chromium`。
